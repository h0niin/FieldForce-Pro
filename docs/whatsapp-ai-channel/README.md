# WhatsApp AI Channel (Hanin)

Users can now create service requests seamlessly by chatting with an AI assistant via WhatsApp. This feature supports both Twilio Sandbox and the official Meta Cloud API.

---

## How to Test

### Prerequisites

1. Expose your local NestJS backend (running on port `3213`) to the internet using a tunneling tool like **ngrok**:
   ```bash
   ngrok http 3213
   ```
2. Copy the secure forwarding URL generated by ngrok (e.g., `https://a1b2-34-56-78-90.ngrok-free.app`).

### Method A: Twilio Sandbox (Recommended for Fast Testing)

#### 1. Configure Twilio Sandbox Webhook
1. Log in to your [Twilio Console](https://console.twilio.com/).
2. Navigate to **Messaging** > **Try it out** > **Send a WhatsApp Message**.
3. Under the **Sandbox Settings** tab:
   - Locate the input field for **"When a message comes in"** (Webhook).
   - Set the URL to:
     ```text
     https://[YOUR_NGROK_SUBDOMAIN].ngrok-free.app/api/whatsapp/webhook/twilio
     ```
   - Ensure the HTTP method is set to **POST**.
   - Click **Save**.

#### 2. Configure FieldForce Pro Settings
1. Go to **Settings** > **WhatsApp Channel** in your browser.
2. Select **Scan QR Code (Twilio)** as the connection method.
3. Enter your **Business Display Name** and optionally your own Twilio credentials. If left blank, it defaults to the Twilio Sandbox default credentials.
4. Customize required intake fields, greeting, and confirmation messages.
5. Click **Save** and then **Generate QR Code**.

#### 3. Initiate the Chat
1. Scan the generated QR code or message `join [sandbox-join-word]` to `+1 415 523 8886`.
2. Start chatting (e.g., *"Hello, I have an HVAC emergency"*).

### Method B: Meta Cloud API (WhatsApp Business API)

This method connects directly to the official Meta WhatsApp Business Platform.

#### 1. Set Up Meta Developer App
1. Go to the [Meta for Developers Console](https://developers.facebook.com/) and register as a developer.
2. Click **Create App** and choose **Other** > **Business** app type.
3. Under your app dashboard, scroll down to **Add products to your app** and click **Set up** next to **WhatsApp**.
4. Link your Meta Business Account (or create a temporary developer one).
5. In the WhatsApp **Getting Started** panel, you will see:
   - **Temporary Access Token** (valid for 24 hours).
   - **Phone Number ID**.
   - **WhatsApp Business Account ID (WABA ID)**.
   - A **Test Phone Number** assigned to your account.

#### 2. Configure FieldForce Pro Settings
1. Navigate to **Settings** > **WhatsApp Channel** in FieldForce Pro.
2. Select **WhatsApp Business API** as the connection method.
3. Enter the credentials from Meta Console:
   - **Meta App ID** & **App Secret**
   - **Phone Number ID**
   - **Access Token**
   - **WABA ID**
   - **Webhook Verify Token**: Enter a custom secret string of your choice (e.g. `my_super_secret_verify_token`).
4. Click **Save**.

#### 3. Verify & Save Meta Webhook
1. Go back to your **Meta App Dashboard** > **WhatsApp** > **Configuration**.
2. Click **Edit** next to Webhooks configuration:
   - **Callback URL**: Enter `https://[YOUR_NGROK_SUBDOMAIN].ngrok-free.app/api/whatsapp/webhook/meta`
   - **Verify Token**: Enter the exact same custom secret string you saved in FieldForce Pro settings (e.g., `my_super_secret_verify_token`).
3. Click **Verify and Save**. Meta will make a verification request to your local server, which will automatically confirm it.
4. Once verified, click **Manage** next to Webhook Fields:
   - Locate the **messages** row and click **Subscribe**.
   - Click **Done**.

#### 4. Initiate the Chat
1. On your **Meta Developer Portal** under **Getting Started**, add your personal WhatsApp number as a recipient in the "To" test field and send a template message to authorize the sandbox.
2. Open WhatsApp on your phone and send a message to the Meta **Test Phone Number** (e.g. *"Hi, I need to request a plumber"*).
3. The AI will respond, guide you through the intake, and automatically create the ticket.

## Files Changed

### Backend Changes

#### 1. `server/src/WHATSAPP_CHANNELS/` (New Module)
- **`whatsapp_ai.service.ts`**: Handles AI orchestration using generative AI to parse user messages and generate responses.
- **`whatsapp_channels.service.ts`**: Manages the configuration, fetching QR codes for Twilio Sandbox, and saving settings.
- **`whatsapp_webhook.service.ts`**: Processes incoming webhooks from both Twilio and Meta, coordinates with the AI service, and creates tickets.
- **`whatsapp.controller.ts`**: Defines REST endpoints for settings configuration and webhook receivers.

#### 2. System Modules
- **`server/src/app.module.ts`**: Registered the new WhatsApp module.
- **`server/src/database/database.module.ts`**: Configured WhatsApp channel models.
- **`server/src/shared/constants/keynames.ts`**: Added any new constants used by the module.

#### 3. Dependencies
- **`server/package.json`** & **`server/package-lock.json`**: Added `@google/genai` (or similar) dependencies.

### Frontend Changes

#### 1. `web/src/pages/settings/WhatsAppChannelSettingsPage.tsx`
- **New Page**: Provides a UI to select the connection method (Twilio Sandbox vs. Meta Business API) and configure the necessary credentials, greeting messages, and required fields.

#### 2. `web/src/api/whatsapp.api.ts`
- **New API Wrappers**: Methods to fetch and save WhatsApp channel configurations and fetch the QR code for Twilio.

#### 3. `web/src/components/layout/Sidebar.tsx`
- **Modified**: Added the "WhatsApp Channel" link under Settings.

#### 4. `web/src/routes.tsx`
- **Modified**: Added the route for `/settings/channels/whatsapp`.

#### 5. `web/public/locales/*/common.json`
- **Modified**: Added translation keys (`whatsappChannel`) for English, Arabic, Hindi, and Malayalam.
