# Reports, Dashboards, and Analytics

---

## Dashboard

### What is the Dashboard?
The Dashboard is the home screen after login. It shows a real-time summary of your business operations through widgets — charts, counters, and maps.

### Accessing the Dashboard
Click **Dashboard** in the sidebar (or the FieldForce Pro logo).

### Default Dashboard Widgets
The default dashboard typically includes:
- **Jobs Today** — count of appointments scheduled for today
- **Open Work Orders** — total work orders not yet completed
- **Revenue This Month** — total invoice value collected this month
- **Technician Utilisation** — percentage of technicians currently on active jobs
- **SLA Compliance Rate** — percentage of jobs resolved within SLA
- **Overdue Invoices** — count of invoices past their due date
- **Recent Activity Feed** — latest actions across the platform
- **Live Map** — real-time technician locations

### Customising the Dashboard
1. Click **Customise Dashboard** (pencil icon, top-right of the dashboard).
2. The Dashboard Builder opens.
3. Click **+ Add Widget** and choose from the widget library.
4. Drag widgets to reorder them.
5. Resize widgets by dragging their corners.
6. Click **Save Layout**.

### Dashboard Builder
Go to **Dashboard → Dashboard Builder** to create a custom dashboard from scratch with any combination of:
- **KPI counters** (single numbers with trend arrows)
- **Bar charts** (e.g., revenue by month)
- **Line charts** (e.g., jobs completed over time)
- **Pie charts** (e.g., work order status distribution)
- **Data tables** (e.g., top 10 customers by revenue)
- **Live map** widget
- **Recent records** list

## Reports

### What is a Report?
A report is a structured view of data filtered and aggregated by specific criteria. Reports can be exported to PDF, CSV, or Excel.

### Accessing Reports
Click **Reports** in the sidebar.

### Standard Reports Available

| Report Name | What It Shows |
|-------------|---------------|
| **Work Order Summary** | All work orders with status, priority, assigned tech, completion time |
| **Technician Performance** | Jobs completed, on-time rate, customer rating per technician |
| **Revenue Report** | Invoiced amount, collected amount, outstanding, by period |
| **SLA Compliance Report** | SLA breaches, near-breaches, compliance rate by priority |
| **Invoice Aging Report** | Overdue invoices grouped by age (30/60/90+ days) |
| **Timesheet Summary** | Total hours worked per technician per period |
| **Asset Service History** | All work orders for each asset |
| **Service Request Report** | Incoming requests, resolution times, conversion rates |
| **Customer Activity Report** | Jobs, invoices, and payments per customer |

### Running a Standard Report
1. Go to **Reports** in the sidebar.
2. Click the report name.
3. Set the **Date Range** and any other filters.
4. Click **Run Report**.
5. The report displays. Click **Export PDF**, **Export CSV**, or **Export Excel** to download.

### Custom Report Builder
The Custom Report Builder is **not available yet — it is marked "Coming Soon" and is under development.** The page shows a "Coming Soon" notice ("The custom report builder is currently under development. Use the pre-built reports for now.") with a single **View Reports** button that returns to the pre-built Reports dashboard. There are no field pickers, filters, data-source selectors, or save/export controls on this page. For now, use the pre-built reports and export them to CSV/Excel.

## Natural Language Analytics (NL Analytics)

### What is NL Analytics?
NL Analytics lets you ask questions about your data in plain English, without needing to know how to build a report or write a query.

### Accessing NL Analytics
Go to **Analytics** in the sidebar.

### How to Use NL Analytics
1. Type your question in the search bar.
2. Click **Ask** or press Enter.
3. The platform interprets your question and generates a chart or table with the answer.

### Example Questions You Can Ask
- "Show me all work orders completed last month by technician"
- "What was our total revenue in Q3?"
- "Which customers had the most overdue invoices this year?"
- "How many work orders were breached SLA in the past 30 days?"
- "Compare technician performance between this month and last month"
- "List all assets that have not been serviced in over 12 months"

### NL Analytics Tips
- Be specific with dates ("last month", "Q2 2025", "past 7 days")
- Mention the entity type (work orders, invoices, customers, technicians, assets)
- You can ask follow-up questions to refine the results

## Live Map Dashboard

### What is the Live Map Dashboard?
A dedicated full-screen view of all technician locations in real time, with job site pins and status information.

### Accessing the Live Map Dashboard
Go to **Dashboard → Live Map Dashboard** or **Scheduling → Map View**.

### What You Can See
- **Blue dots** — active technicians with their name and current status
- **Colored pins** — job sites (color by status: green = completed, orange = in progress, red = urgent)
- **Technician info card** — click a technician dot to see their name, current job, phone number
- **Job info card** — click a job pin to see work order details and assigned technician
