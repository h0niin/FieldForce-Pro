# WF-WRK-create-crew — Create a Technician Crew

## Prerequisites
- User must have the `workforce:create` permission (Admin or Dispatcher).
- At least two technicians must exist in the system.

## Steps

1. Click **Workforce** in the sidebar, then select **Crews** (or navigate to **Workforce → Crews**).
2. Click **+ New Crew**.
3. Fill in:
   - **Crew Name** (required) — e.g., "Team Alpha", "North Zone Crew 1"
   - **Crew Lead** — select the technician who leads the crew from the dropdown
   - **Territory** (optional) — assign the crew to a specific service territory
4. Click **+ Add Members** to add more technicians to the crew:
   - Search for technicians by name
   - Click each technician to add them
   - Each member shows their name and current role
5. Click **Save**.

## Result
A crew is created. The crew appears in the crews list and can be assigned to work orders and appointments as a unit. All crew members see the same appointments in their schedule.
