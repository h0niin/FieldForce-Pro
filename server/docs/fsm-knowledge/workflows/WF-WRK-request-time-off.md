# WF-WRK-request-time-off — Request Time Off

## Prerequisites
- User must be logged in (any technician or team member).

## Steps (Technician — Mobile App)

1. Open the mobile app.
2. Tap **More** (bottom tab bar).
3. Tap **Time Off** or **Leave Requests**.
4. Tap **+ Request Time Off**.
5. Select the **Leave Type**: Annual Leave, Sick Leave, Personal Leave, Training, Other.
6. Select the **Start Date** and **End Date** using the date picker.
7. Enter a **Reason** (optional for some leave types).
8. Tap **Submit Request**.
9. The request is sent to your manager for approval.
10. You will receive a push notification when your manager approves or rejects the request.

## Steps (Web App)

1. Go to **Workforce → Time Off** in the sidebar.
2. Click **+ Request Time Off**.
3. Fill in the **Leave Type**, **Start Date**, **End Date**, and **Reason**.
4. Click **Submit**.

## Approving Time Off (Manager/Admin)

1. Go to **Workforce → Time Off**.
2. Filter by **Status = Pending** to see open requests.
3. Click a request to open it.
4. Click **Approve** or **Reject**.
5. If rejecting, enter a reason. The technician is notified.

## Result
- If approved: the technician's schedule shows as unavailable for those dates on the Dispatch Board. Dispatchers cannot schedule appointments for them during that period.
- If rejected: the technician sees the rejection reason and can resubmit if needed.
