# WF-REP-run-standard-report — Run a Standard Report

## Prerequisites
- User must have the `reports:read` permission.

## Steps

1. Click **Reports** in the left sidebar.
2. The Reports list shows all available standard and custom reports.
3. Click the name of the report you want to run (e.g., "Work Order Summary", "Revenue Report", "Technician Performance").
4. The report filter panel opens. Set:
   - **Date Range** — select a start and end date (e.g., Last 30 Days, This Month, Custom Range)
   - Any other filters shown for that specific report (e.g., Technician, Status, Priority)
5. Click **Run Report**.
6. The report displays with charts and/or a data table.
7. To export:
   - Click **Export PDF** to download a formatted PDF
   - Click **Export CSV** to download raw data in spreadsheet format
   - Click **Export Excel** to download an Excel (.xlsx) file
8. To print: click **Print** or use your browser's print function after opening the PDF.

## Result
The report is displayed and/or downloaded.
