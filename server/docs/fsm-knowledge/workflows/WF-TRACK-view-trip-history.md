# WF-TRACK-view-trip-history — View a Technician's Trip History

## Prerequisites
- User must have the `tracking:read` permission (Admin, Manager, or Dispatcher).

## Steps

1. Click **Trips** in the left sidebar (or go to **Scheduling → Trip History**).
2. The Trips list shows all recorded technician trips with: Technician name, Start/End location, Start/End time, Distance (km), linked Appointment.
3. To filter the list:
   - Filter by **Technician** — select one technician from the dropdown
   - Filter by **Date Range** — select start and end dates
   - Filter by **Appointment** — find trips linked to a specific job
4. Click on a trip row to open the trip detail page.
5. The detail page shows:
   - An interactive map with the route drawn as a line
   - Start and end location markers
   - Start time, end time, total distance
   - The technician's name and the linked appointment
   - A playback button (if available) to animate the route
6. To export trip data for mileage claims or payroll:
   - Apply your date and technician filters on the list page
   - Click **Export CSV** to download all filtered trip records

## Result
A visual and tabular view of a technician's travel history for compliance, mileage claims, and job visit verification.
