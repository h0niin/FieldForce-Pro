# WF-DASH-add-widget — Add a Widget to the Dashboard

## Prerequisites
- User must have the `dashboard:edit` permission or be the owner of a custom dashboard.

## Steps

1. Click **Dashboard** in the left sidebar (or the FieldForce Pro logo).
2. Click the **Customise** button (pencil icon, top-right corner of the dashboard).
3. The Dashboard Builder opens. Existing widgets are shown on the canvas.
4. Click **+ Add Widget** (usually a large plus button or visible in a widget panel).
5. The Widget Library opens. Browse or search for the type of widget you want:
   - **KPI Counter** — displays a single key number (e.g., "Open Work Orders: 24") with an optional trend arrow
   - **Bar Chart** — compares values across categories or time periods
   - **Line Chart** — shows trends over time
   - **Pie/Donut Chart** — shows proportion/distribution
   - **Data Table** — shows a list of records with columns
   - **Live Map** — shows real-time technician locations
   - **Recent Records** — a scrollable list of the most recent records in a module
6. Click the widget type to add it to the canvas.
7. A settings panel opens for that widget:
   - **Title** — the heading shown on the widget
   - **Module** — what data to show (Work Orders, Invoices, etc.)
   - **Metric** — what to measure (count, sum, average)
   - **Filter** — restrict to specific statuses, date ranges, or other conditions
   - **Date Range** — e.g., "This Month", "Last 7 Days", "Year to Date"
8. Click **Save Widget** or **Apply**.
9. Drag the widget to the desired position on the canvas.
10. Resize by dragging the widget's corner handles.
11. Click **Save Layout** (top-right) to confirm all changes.

## Result
The new widget appears on the dashboard and updates automatically with live data.
