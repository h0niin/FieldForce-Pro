# WF-VOICE-record-voice-note — Record a Voice Note on a Work Order

## Prerequisites
- Technician must be logged into the mobile app.
- Microphone permission must be granted to the app.

## Steps (Mobile App)

1. Open the **mobile app**.
2. Navigate to the work order (tap **Schedule** or find it in **Work Orders**).
3. Open the work order detail.
4. Scroll to the **Notes** section.
5. Tap the **Microphone** icon (🎤) next to the note input.
6. Tap **Record** — a timer starts showing the recording duration.
7. Speak clearly. Describe the fault, what was done, parts used, or any customer comments.
8. Tap **Stop** when finished.
9. The recording is sent for transcription. This takes approximately 10–30 seconds.
10. The transcribed text appears in the note input box.
11. Review the transcription. Edit any words that were transcribed incorrectly.
12. Tap **Save Note**.

## Steps (Web App)

1. Go to **Voice Notes** in the left sidebar to see all previously recorded notes, or open a work order.
2. Recording is primarily designed for the mobile app. On the web, you can view and manage existing voice notes.

## Result
A note is added to the work order with the transcribed text. The note is labelled as a "Voice Note" and shows the technician's name and timestamp. The original audio file is stored alongside the transcription.
